Zo koppel je je mailbox

  1. Maak een apart e-mailadres voor je facturen, bijvoorbeeld facturen@jouwbedrijf.nl {{ info("factuurmailbox") }}. Laat leveranciers daar naartoe mailen, of stuur facturen zelf door.
  2. Gebruikt je mailprovider een apart wachtwoord voor programma's? Maak dan een app-wachtwoord {{ info("app_wachtwoord") }} aan.
  3. Zet de gegevens in het bestand .env in de map van dit programma: 
    IMAP_HOST=imap.jouwprovider.nl
IMAP_USER=facturen@jouwbedrijf.nl
IMAP_PASSWORD=jouw-app-wachtwoord
# Niet verplicht:
# IMAP_PORT=993
# IMAP_FOLDER=INBOX
# IMAP_PROCESSED_FOLDER=Verwerkt
# IMAP_POLL_INTERVAL_MINUTES=15
  4. Start het programma opnieuw en druk hier op Verbinding testen.

Afgehandelde mail wordt naar de map {{ cfg.processed_folder }} verplaatst; er wordt niets verwijderd. Verwijder je later een document uit je inbox, dan komt het niet terug uit dezelfde mail.
